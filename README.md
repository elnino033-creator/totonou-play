# 整いゲーム（仮公開版）

スマホ縦画面向けのドット絵ゲーム。お風呂・サウナ・水風呂・休憩を組み合わせ、制限時間内に「ととのう」ことを目指します。

- 遊び方: `index.html` をブラウザで開く（このリポジトリでは GitHub Pages で公開）
- はじめての方はステージ選択の「チュートリアル」から
- 仮公開のため、検索エンジンには載せない設定にしています
